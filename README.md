# Sistema de Registro de Estudiantes - Refactorización y Evolución

## Descripción
Proyecto de refactorización y evolución correspondiente a la Evaluación del Primer Bimestre de Sistemas Ágiles.

## Mejoras Implementadas
* **Código Limpio y POO:** Modularización de clases `Estudiante` y `GestorEstudiantes`.
* **Manejo de Excepciones:** Validaciones explícitas de nombres y rango de notas (0 a 10).
* **Evolución del Sistema:** Incorporación del estado académico `SUPLETORIO` (18 a 23.9 puntos).
* **Pruebas Automatizadas:** Cobertura de pruebas unitarias con Pytest.
